Build Portless into a complete private PaaS for machines without public IPs. Use Cloudflare Tunnel for public ingress, Linux kernel WireGuard via Netmaker for high-performance internal machine networking, Nomad for scheduling, Consul for service discovery, Traefik/Caddy for routing, TypeScript/Fastify/tRPC/Postgres/Drizzle/Temporal for the control plane, Vite React for the dashboard, and Go for the node-agent. Keep custom code minimal, integrate mature projects, avoid arbitrary remote shell, enforce RBAC/audit/dry-run/confirmation, support zero-downtime deploys when safe, explain unsafe stateful failover, and make 20+ apps manageable in the dashboard. Follow the docs and milestones in this repo, keep tests passing after every change, and start from Milestone 1 in `docs/09-development-roadmap.md`.
